# Badge icon sources

- `csharp.svg`: C# paths adapted from [Devicon](https://github.com/devicons/devicon/blob/master/icons/csharp/csharp-original.svg), recolored for this profile.
- `windows.svg`: Windows paths adapted from [Devicon](https://github.com/devicons/devicon/blob/master/icons/windows11/windows11-original.svg), recolored for this profile.
- `wpf.svg`: uses the [XAML icon from Simple Icons 11.15.0](https://github.com/simple-icons/simple-icons/blob/11.15.0/icons/xaml.svg) to represent WPF/XAML. This is the XAML mark, not a separate WPF logo. [Upstream license](https://github.com/simple-icons/simple-icons/blob/11.15.0/LICENSE.md).

These are static, self-contained badges. They require no scripts, external fonts, or badge-generation service. Brand names and marks belong to their respective owners.
